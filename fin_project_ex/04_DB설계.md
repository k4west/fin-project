# DB/Storage 설계 (MVP는 로컬 저장)

## 로컬 저장 키
- key: portfolio_draft_v1

## 저장 JSON 스키마
```json
{
  "meta": {
    "savedAt": "2026-01-05T13:00:00+09:00",
    "asOf": "2026-01-05",
    "disclaimerVersion": "v1"
  },
  "profile": {
    "horizon": "10_PLUS",
    "volatility": "MED",
    "cashflowNeed": { "enabled": false, "monthlyTarget": null },
    "bigExpense": "NONE",
    "accounts": { "isa": true, "pension": true, "irp": false, "taxable": true }
  },
  "portfolio": {
    "templateId": "T1",
    "weights": { "EQUITY_INDEX": 60, "BOND": 30, "CASH": 10, "DIVIDEND": 0 }
  },
  "result": {
    "variants": [...],
    "assumptions": [...]
  }
}
```

## 검증 규칙
- weights 합 = 100
- 현금흐름형(T4)에서 DIVIDEND > 0이면 경고 동의 플래그 필요(프론트에서 처리)

## 추후 서버 저장 확장(참고)
- userId(guestId) 기반으로 서버 저장 가능하도록 필드 유지:
  - meta.guestId optional
