# 기능 명세 (MVP)

## 플랫폼/비기능
- 웹(모바일 친화), 게스트 시작
- 데이터 저장: 로컬(localStorage)
- PDF 생성: 서버(FastAPI)에서 폰트 임베드로 생성, 1장 구성

---

## Must (MVP)
### 1) 온보딩(설문 5문항)
- 입력:
  1) 투자기간: 1~3 / 3~5 / 5~10 / 10+
  2) 변동성 감내: 낮/중/높
  3) 현금흐름 필요: 없음/있음 (+ 월 목표 옵션)
  4) 큰 지출 예정: 없음/1년 내/3년 내
  5) 계좌 보유: ISA/연금/IRP/없음/모름
- 출력: 추천 템플릿(T1~T5) 자동 선택 (사용자 수정 가능)

### 2) Starter 포트폴리오 생성/편집
- 템플릿 선택/변경
- 자산군 비중 편집(합 100 검증)
- 예시 표기(카테고리 + 대표지수/ETF 예시):
  - 주식지수: S&P 500, MSCI ACWI 등
  - 채권: 국채/종합채권(중장기) 등
  - 현금: MMF/단기채 등
  - 배당: 배당 ETF/커버드콜 ETF/리츠 등 (강한 경고)

### 3) 계좌 배치 추천(3안 고정)
- BASE / GROWTH / CASHFLOW 3가지 안 제공
- 각 안 구성:
  - 계좌별 배치(ISA/연금/IRP/일반) + 이유(짧게)
  - 주의사항/가정(고정 박스)
  - 다음 행동 체크리스트(3~5개)

### 4) 저장/불러오기(로컬)
- 포트/설문/추천 결과를 로컬에 저장
- 재방문 시 마지막 상태 복원
- “새로 시작” 버튼(로컬 삭제)

### 5) PDF 다운로드
- 서버에 payload 전송 → PDF(1장) 반환
- 한글 폰트 임베드(깨짐 방지)
- PDF 구성:
  1) 요약(설문/템플릿)
  2) 자산 비중 표
  3) 추천 3안 표
  4) 면책/기준시점(하단 고정)

---

## Should (후순위)
- 추천안 비교 표(차이점 강조)
- “현금흐름형”에서 커버드콜/리츠 경고를 더 구체화(체크박스 동의)

## Could (나중)
- 로그인/서버 저장/가족 공유
- 세제 정밀 계산(수치)
- 금융 데이터 연동

---

## 화면 목록
1) Landing (/)
2) 설문 (/onboarding)
3) 템플릿/비중 편집 (/portfolio)
4) 결과 (/result)
5) PDF 다운로드(결과 화면 버튼)

---

## 엣지 케이스(최소 10)
- 비중 합 != 100
- 설문 미완료 상태에서 결과 진입
- 계좌 보유 “모름” 처리
- 현금흐름 목표 입력이 과도/불명확
- 단기목표인데 공격형 선택
- 배당/커버드콜 선택 시 경고 동의 필요
- PDF 생성 실패(네트워크/서버)
- 로컬 저장 비활성/용량 초과
- 모바일에서 슬라이더 조작성
- 기준 시점(disclaimer 버전) 변경 시 기존 결과 표기
