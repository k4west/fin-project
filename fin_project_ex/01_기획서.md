# 계좌 배치 결정기 (MVP)

## 한 줄 요약
보유 상품이 없어도, 상황 설문만으로 "기본 포트폴리오(예시)"를 생성하고 ISA/연금저축/IRP/일반계좌에 어떻게 배치할지 3가지 안을 제안하는 웹 서비스.

## 타깃
- 초심자(상품/계좌 구조가 헷갈리는 사람)
- 장기 투자자(ETF 중심) / 현금흐름 니즈 일부 보유
- "보유 상품 없음" 상태에서도 시작하고 싶은 사용자

## 핵심 가치
- 종목 추천이 아니라 "계좌 배치 결정"에 집중
- 금융 API 없이도 작동(수기/설문 기반)
- 결과를 PDF 1장으로 저장/공유

## 사용자 문제
- ISA/연금저축/IRP/일반계좌에 무엇을 넣어야 하는지 모름
- 배당/커버드콜은 현금흐름이 좋아 보여도 구조/리스크가 헷갈림
- 단기 목표(1~3년)인데도 주식 비중을 높게 가져가 실수

## 해결 방식 (MVP)
1) 5문항 설문 → 2) Starter 템플릿(가상 포트) 생성/수정 → 3) 계좌 배치 3안 제시 → 4) PDF 1장 다운로드
- 저장은 로컬(localStorage)로 제공

## Starter 템플릿(확정)
자산군: 주식지수 / 채권 / 현금 / 배당(인컴: 배당 ETF/커버드콜/리츠 등 "예시"로만 제공)

- T1 초심자 기본(균형): 주식 60 / 채권 30 / 현금 10 / 배당 0
- T2 안정형: 주식 30 / 채권 55 / 현금 15 / 배당 0
- T3 공격형: 주식 85 / 채권 10 / 현금 5 / 배당 0
- T4 현금흐름형: 주식 40 / 채권 20 / 현금 10 / 배당 30 (커버드콜 예시 포함, 경고 강하게)
- T5 단기목표(1~3년): 주식 20 / 채권 45 / 현금 35 / 배당 0

## KPI
- 온보딩 완주율(설문 → 결과 도달)
- PDF 다운로드율
- 7일 재방문율(로컬 저장 포트 재열람/수정)

## 면책/가정(고정 표시)
- 본 서비스는 교육/정보 목적이며 투자 조언이 아님
- 원금 손실 가능, 과거 성과가 미래 수익을 보장하지 않음
- 세제/제도는 특정 기준 시점(예: 2026-01) 단순화 모델이며 실제와 다를 수 있음

## 범위(Out of Scope)
- 실시간 시세/증권사 연동/자동 매매
- 개인별 세금 정밀 계산(절세액 숫자 확정)
- 개별 종목 “확정 추천” (예시는 카테고리/대표지수/ETF 예시 수준)
